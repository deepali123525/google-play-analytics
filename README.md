# Google Play Store Data Analysis – Internship Project

## Project Overview
This project was completed as part of my Data Analytics Internship and focuses on analyzing application data from the Google Play Store using Python and Plotly.

## Dataset Used
- Play_Store_Data.csv
- User_Reviews.csv

## Tools & Technologies
- Python 3.11
- Pandas
- NumPy
- Plotly (Graph Objects & Express)
- Jupyter Notebook

## Data Cleaning & Preprocessing
- Converted ratings, reviews, installs, and prices into numeric format
- Standardized app sizes into MB
- Parsed date columns into datetime format
- Removed invalid, missing, and inconsistent values

## Tasks & Visualizations

### Task 1: Grouped Bar Chart
- Average Rating vs Total Reviews (Top 10 Categories)
- Filters based on rating, size, and update month
- Dashboard visible between 3 PM – 5 PM IST

### Task 2: Choropleth Map
- Global installs by top 5 app categories
- Dashboard visible between 6 PM – 8 PM IST

### Task 3: Dual Axis Chart
- Average installs vs revenue (Free vs Paid Apps)
- Dashboard visible between 1 PM – 2 PM IST

### Task 4: Time Series Line Chart
- Category-wise installs trend over time
- Dashboard visible between 6 PM – 9 PM IST

### Task 5: Bubble Chart
- App size vs rating
- Dashboard visible between 5 PM – 7 PM IST

### Task 6: Stacked Area Chart
- Cumulative installs over time
- Dashboard visible between 4 PM – 6 PM IST

## Key Learnings
- Real-world data cleaning
- Advanced filtering logic
- Interactive visualization
- Data storytelling

## Challenges Faced
- Inconsistent data formats
- Plotly DataFrame mismatch errors
